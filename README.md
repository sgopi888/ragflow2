# RAGFlow – Custom Fork for General RAG Systems

This repository is a personal fork of the official RAGFlow project by Infiniflow.

Purpose of this fork:
- Experimenting with Retrieval-Augmented Generation workflows
- Custom configurations for local and cloud deployment
- Integration with external LLM providers
- Deployment experiments on platforms like Railway and local Docker

Original source:
https://github.com/infiniflow/ragflow

This fork keeps upstream compatibility while allowing custom changes for personal and research use.
